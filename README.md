# E-Commerce Sales Analysis Using Olist Dataset

## Project Overview

This project analyzes the Olist E-commerce dataset to identify sales trends, customer behavior, top-performing product categories, and regional performance.

## Objectives

* Perform data cleaning and preprocessing
* Analyze sales performance
* Identify top revenue-generating categories
* Determine best-performing regions
* Study customer review patterns
* Create visualizations and dashboards
* Generate business recommendations

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab
* GitHub

## Dataset

Olist Brazilian E-Commerce Dataset

## Key Findings

### Top Revenue Category

Health & Beauty

### Best Performing Region

São Paulo (SP)

### Peak Sales Period

November

### Customer Satisfaction

Most reviews received 5-star ratings

## Business Recommendations

1. Increase investment in high-performing product categories.
2. Launch seasonal campaigns during peak sales months.
3. Expand marketing efforts in high-revenue regions.
4. Use bundle offers to increase average order value.
5. Maintain strong customer service to preserve review ratings.

## Project Structure

* Data Cleaning
* Sales Analysis
* Visualizations
* Dashboard KPIs
* Business Insights
